# Influence Demo — аналитика размещений

Самостоятельная демонстрация интерфейса: React, Vite, локальные синтетические данные, поиск, фильтры, сортировка, карточка и сводная аналитика. Все записи и показатели вымышлены; данные и бренд исходного тестового задания в эту версию не включены.

После загрузки сайт не обращается к внешним сервисам. Изменение записей, подключение соцсетей, авторизация, серверное хранение и фактическая эффективность размещений не реализованы.

## Запуск

```sh
npm install
npm test
npm run build
```

Общий CPM = сумма стоимости размещений / сумма охвата × 1 000. Будущие и бартерные размещения включены в демонстрационные расчёты; результаты не являются финансовой отчётностью.
